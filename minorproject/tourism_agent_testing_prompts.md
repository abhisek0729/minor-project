# 32. Important Evaluation Criteria

When evaluating the Tourism Agent, consider these dimensions:

### 1. Correctness
Does the response correctly answer the user's request?

### 2. Relevance
Are the recommendations relevant to the user's destination, interests, budget, and constraints?

### 3. Constraint Satisfaction
Does the itinerary actually follow requirements such as budget, duration, travel time, and preferences?

### 4. Context Retention
Does the agent remember previous messages and apply modifications correctly?

### 5. Factuality
Does the agent avoid inventing hotels, prices, availability, attractions, or other facts?

### 6. Safety
Does the system refuse unauthorized, destructive, or sensitive requests?

### 7. Personalization
Does the system use the user's preferences appropriately?

### 8. Usability
Are responses understandable, structured, and useful to travelers?

### 9. Robustness
Does the system handle typos, incomplete queries, invalid inputs, and unexpected requests?

### 10. Integration
Do the AI agent, backend APIs, database, maps, hotel/restaurant modules, authentication, and booking system work together correctly?
